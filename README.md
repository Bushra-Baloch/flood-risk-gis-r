## 📊 Project Overview

This project analyzes rainfall data (2015–2024) to assess flood risk levels using R. The goal is to classify rainfall into different risk categories and visualize potential flood patterns using GIS tools.

---

## ⚙️ Tools & Technologies

  * dplyr
  * ggplot2
  * lubridate
* **ArcGIS (ArcMap 10.8)**
* **Git & GitHub**

---

## 📁 Data Description

The dataset contains daily rainfall data with:

* YEAR
* DOY (Day of Year)
* RAINFALL (mm)
* DATE

Additional features created:

* Risk Level (Low, Medium, High)
* Risk Index (1–3)
* Latitude & Longitude (Lahore)
